# Small Totems Texture Pack

A lightweight Minecraft resource pack designed for PvP players that reduces totem of undying textures to be less obtrusive and easier to see past during combat.

## Features

- **Compact Totem Textures** — Smaller, cleaner totem visuals
- **PvP Optimized** — Designed to minimize visual clutter during fights
- **Lightweight** — Minimal impact on performance
- **Minecraft 1.20.1+** — Compatible with latest Minecraft versions

## Installation

1. Download the pack as a ZIP file
2. Place it in your `.minecraft/resourcepacks` folder
3. Open Minecraft and go to Options → Resource Packs
4. Select "Small Totems Texture" and click the arrow to move it to "Selected"
5. Done! The pack is now active

## Folder Structure

```
assets/
└── minecraft/
    └── textures/
        └── item/
            └── totem_of_undying.png
```

## Customization

Feel free to modify the textures to suit your preferences:
- Edit PNG files in `assets/minecraft/textures/item/`
- Reload resource packs in-game (F3 + T on Java Edition)
